# Задачи коммивояжёра и рюкзака

Сборник учебных реализаций на C++ для задачи коммивояжёра (*Traveling Salesman Problem, TSP*) и задачи о рюкзаке (*Knapsack Problem*). Каждая папка содержит самостоятельный проект или вариант алгоритма.

| Папка | Содержание |
| --- | --- |
| [`traveling-salesman-problem/`](traveling-salesman-problem/) | Построение маршрута и его улучшение методами 2-opt и 3-opt |
| [`traveling-salesman-problem-2/`](traveling-salesman-problem-2/) | Вариант 3-opt с использованием OpenMP |
| [`knapsack-greedy-heuristics/`](knapsack-greedy-heuristics/) | Две жадные эвристики выбора предметов; рядом с кодом находятся таблицы и изображения результатов |
| [`knapsack-branch-and-bound/`](knapsack-branch-and-bound/) | Метод ветвей и границ для задачи о рюкзаке, пример входных данных и таблица |
| [`genetic-algorithm/`](genetic-algorithm/) | Генетический алгоритм для задачи о рюкзаке |

Оптимизационные версии этих задач являются NP-трудными; их варианты в форме задачи принятия решения являются NP-полными. Методы в этом репозитории могут находить приближённые или точные решения в зависимости от алгоритма.

Исходные ZIP-архивы сохранены локально как резервные копии и исключены из Git через `.gitignore`.
